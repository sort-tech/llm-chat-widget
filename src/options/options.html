페이지 챗봇 설정

LiteLLM(OpenAI 호환) 서버 정보와 답변 방식을 정합니다.

연결

LiteLLM 프록시 주소입니다. /chat/completions 는 자동으로 붙습니다. (예: http://localhost:4000, http://localhost:4000/v1)
이 브라우저 프로필의 확장 프로그램 저장소에 평문으로 보관됩니다. 공용 PC 에서는 사용 후 지워 주세요.
LiteLLM config.yaml 의 model_name 과 같아야 합니다.

답변

모든 대화의 맨 앞에 붙는 지시문입니다.
0 = 서버 기본값
데이터가 들어오는 동안에는 초기화됩니다.

페이지 참조

길면 앞·뒤를 남기고 가운데를 생략합니다.

패널 위치

참고

  • 단축키는 chrome://extensions/shortcuts (Edge 는 edge://extensions/shortcuts) 에서 바꿉니다.
  • 대화 내용은 탭별로 보관되며 브라우저를 닫으면 사라집니다.
  • 페이지 본문은 질문할 때마다 새로 읽어 프롬프트에 담기며, 설정한 서버로만 전송됩니다.
